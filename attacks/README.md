# Attacks

`01_FGSM` adapts FGSM to regression: instead of pushing a classifier's loss up, it steps directly in the direction that increases the model's own predicted output, ascending the price itself. The attack is masked to a "reportable" subset of features (income, house age, room and bedroom counts, occupancy) that an individual could plausibly misstate about their own property, leaving location and census population untouched, and every perturbed value is clipped back to the dataset's real observed range so a large epsilon cannot report a physically nonsensical figure like negative average occupancy.

Evaluated on a real sample of 100 test-set houses, already a small, plausible-looking change moves the prediction substantially: at epsilon=0.05 (in standardized units, a small fraction of one standard deviation per feature) the average predicted value already rises 10.6%, with 52% of houses crossing a 10%-inflation threshold; by epsilon=0.2 that threshold-based success rate reaches 100%. A single concrete example makes the mechanism vivid: a house predicted at $62,486 is reported, after epsilon=0.5, at $177,190 (+183.6%), by nudging income, age, room count, bedroom count, and occupancy each by less than they individually vary across the dataset. This is the tabular version of the same lesson FGSM teaches everywhere else in this family, a model that looks accurate on real data can still be trivially steered by an input it was never defended against, only here the "input" is a form field, not a pixel.

# Models

`01_train_regressor` trains `HousePriceNet`, a small 3-layer MLP, on the California Housing dataset (Pace & Barry, 1997): 8 numeric features describing a census block group predicting median house value. Features are standardized before training, which matters more here than in the vision/audio repos since the 8 features sit on completely different natural scales (income in tens of thousands, room counts in single digits, population in thousands); standardization is also what makes a single epsilon in `attacks/` apply fairly across features. Test performance lands at R²=0.694, RMSE $63,278, a real, usable baseline for a model this small, not a strong one, consistent with this repo family's honest-baseline pattern elsewhere (TrafficNet in vision, the keyword spotter in audio).
